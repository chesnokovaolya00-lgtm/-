# Профессиональный корректировщик каталогов

Desktop-инструмент для переноса правок между Excel-каталогами поддержки. Сверяет исходный файл (с цветными пометками изменений — красный/жёлтый/зелёный) с целевым каталогом и автоматически переносит удаления, точечные правки и новые строки.

## Установка (для пользователей)

1. Скачайте файл **`Корректировщик каталогов.exe`** из этого репозитория (кнопка «Code» → «Download» либо открыть файл и нажать «Download raw file»).
2. Запустите `.exe` — установка не требуется, Python тоже не нужен.
3. При первом запуске Windows SmartScreen может показать предупреждение «Windows защитила ваш компьютер» (т.к. файл не подписан цифровой подписью издателя) — нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Как пользоваться
1. Выбрать исходный файл (с пометками изменений) и корректируемый файл (целевой каталог).
2. Заполнить поля «Изменения по запросу» и «Кем внесены изменения».
3. Нажать «Применить корректировки». Результат сохраняется в целевой файл, журнал обработки отображается внизу окна.

## Требования
Windows 10/11.

## Для разработчиков

Запуск из исходников:
```bash
pip install -r requirements.txt
python app.py
```
или просто запустить `run.bat`.

Сборка `.exe`:
```bash
pip install pyinstaller
pyinstaller "Корректировщик каталогов.spec"
```
Готовый файл появится в `dist/`.
